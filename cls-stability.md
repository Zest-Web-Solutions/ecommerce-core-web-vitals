# Cumulative Layout Shift (CLS) and Visual Stability

Cumulative Layout Shift (CLS) measures unexpected visual movement during page loading.

Poor visual stability damages user experience and ecommerce trust.

## Common Causes of CLS

Typical layout shift causes:

* images without dimensions
* dynamically injected content
* late-loading fonts
* unstable banners
* third-party embeds
* app-generated DOM shifts

## Optimization Techniques

Recommended improvements:

* reserve space for media assets
* preload critical fonts
* avoid injecting content above existing elements
* stabilize dynamic components
* reduce layout recalculations

## Ecommerce Importance

Stable storefronts improve:

* usability
* product browsing
* checkout experience
* mobile interaction
* conversion consistency
